# AGILAB Software Lab Guide

歡迎來到 AGILAB 軟體開發與研究規範手冊。本倉庫匯集了實驗室所有專案通用的開發標準、環境配置與協作流程。

Welcome to the AGILAB Software Development and Research Guidelines. This repository centralizes the development standards, environment configurations, and collaboration workflows for all research projects within the lab.

## 📖 核心手冊 (Core Guidelines)

*   **[快速啟動與貢獻指南 (Contribution SOP)](docs/CONTRIBUTING_zh.md)**: 
    *   如何使用 [SoftwareTemplate](https://github.com/AGILAB-NTNU/SoftwareTemplate) 建立新專案。
    *   分支策略 (Main/Dev/Feature) 與開發流程。
*   **[研究可重現性指南 (Reproducibility Guide)](docs/REPRODUCIBILITY.md)**:
    *   隨機種子鎖定 (Seed Everything) 的標準實作。
    *   決定性演算法 (Determinism) 與環境一致性規範。
*   **[環境管理指南 (Conda & Environment)](docs/CONDA_GUIDE_zh.md)**: *(即將推出)*
    *   處理 CUDA、物理模擬器與複雜依賴的實踐。
*   **[專案生命週期 (Project Lifecycle)](docs/LIFECYCLE_zh.md)**: *(即將推出)*
    *   從開案開發到論文發表後的程式碼封存與開源 SOP。

## 🛠️ 基礎建設 (Infrastructure)

*   **[軟體範本 (SoftwareTemplate)](https://github.com/AGILAB-NTNU/SoftwareTemplate)**: 
    所有研究專案的起點，內含標準目錄結構、Ruff 程式碼檢查與自動化文件站。

## 🤝 聯絡資訊 (Contact)

如果您對規範有任何建議，請聯繫實驗室負責人或透過 Issue 提出討論。
If you have suggestions, please contact the lab lead or open an issue.
